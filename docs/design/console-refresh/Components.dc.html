Type is signalled twice — a 2px rail and a tinted pill — instead of once, loudly. The old chip flooded the type colour behind near-black text, which made a label the highest-contrast element in a list of a hundred rows. Content gets two lines instead of a hard one-line truncate; the relative time leaves the metadata run and becomes its own right-aligned tabular column, so a scan down the list reads as a column of times rather than as the tail of nine sentences.

Buttons

Every glyph is inline SVG on a 24px grid at 1.7 stroke. The console currently sets ⬇, 🗑 and ✕ as text, so they render as three unrelated typefaces and shift baseline per platform.

The type filter has four fixed values that already own colours. As a segmented control it shows the whole vocabulary at rest and its selected state carries the type colour — a <select> hides all four behind a click and reports the choice in grey.

Inputs
