Supersession is ordered by when a claim was stated, not when it was stored. A new keyed fact or instruction replaces the memory sharing its topic key only if its knowledge time is later; a replayed or back-filled transcript that arrives carrying an older stated time is stored already superseded, kept as history and never embedded, so it cannot overwrite current knowledge.
